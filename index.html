01 / Начало работы

Подключение

Для InSales и обычного script используйте готовые browser-build/nano-lightbox.min.js и browser-build/nano-lightbox.css. JS предоставляет window.NanoLightbox. Файлы прикрепляются к GitHub Release и входят в npm-пакет; после публикации доступны через jsDelivr. Пример инстансов ↗ · Выпуск версии ↗

Соберите библиотеку командой npm run build и скопируйте каталог dist на свой сайт. Сохраняйте файлы рядом друг с другом — модули используют относительные импорты.

index.html 
<link rel="stylesheet" href="/nano/core.css">
<script type="module" src="/nano/auto.js"></script>

<!-- Только для галерей -->
<link rel="stylesheet" href="/nano/gallery.css">

<!-- Только для миниатюр -->
<link rel="stylesheet" href="/nano/thumbs.css">

Галерея загружается по первому клику. Модуль миниатюр — только при их включении.

app.js 
import { open, close } from 'nano-lightbox/core';
import 'nano-lightbox/core.css';

const dialog = document.getElementById('contact');
document.querySelector('#trigger').addEventListener('click', () => {
  open(dialog);
});

Импорты для локально установленного пакета. Ядро не устанавливает глобальные обработчики. Для автоматического подключения импортируйте nano-lightbox.

02 / Примеры

Модальные окна

Добавьте готовый <dialog> и кнопку с его ID. Библиотека откроет окно, заблокирует прокрутку страницы и вернёт фокус после закрытия.

Попробуйте в действии

Окно обратной связи

Откройте окно и попробуйте Tab и Esc.

HTML 
<button data-nl-open="contact">Открыть окно</button>

<dialog id="contact" data-nl-modal aria-labelledby="title">
  <h2 id="title">Обратная связь</h2>
  <label>Имя <input autofocus></label>
  <button data-nl-close>Закрыть</button>
</dialog>

Для закрытия с результатом используйте <form method="dialog">. Значение нажатой кнопки попадёт в dialog.returnValue. Полный пример с формой ↗

03 / Примеры

Мобильное меню

То же ядро, другой CSS. Атрибут data-nl-drawer превращает диалог в панель от начала или конца экрана. Содержимое остаётся обычной навигацией.

Выезжающая панель

Навигация у края экрана

Высота следует за мобильной адресной строкой.

HTML 
<button data-nl-open="menu">Меню</button>
<dialog id="menu" data-nl-drawer="end" aria-label="Навигация">
  <button data-nl-close autofocus>Закрыть</button>
  <nav><a href="/catalog">Каталог</a></nav>
</dialog>

Используйте start или end. Переходы по якорям и переключение на десктопную навигацию настраиваются в коде сайта. Пример с адаптивной навигацией ↗

04 / Примеры

Галереи изображений

Объедините ссылки одинаковым значением data-nl-gallery. Галерея откроется с выбранного изображения, а порядок слайдов будет соответствовать порядку ссылок в документе.

HTML 
<div data-nl-thumbs>
  <a href="/large-1.jpg" data-nl-gallery="travel"
     data-nl-caption="Озеро среди гор">
    <img src="/small-1.jpg" alt="Озеро среди гор">
  </a>
  <a href="/large-2.jpg" data-nl-gallery="travel">
    <img src="/small-2.jpg" alt="Горный хребет">
  </a>
</div>
Миниатюры по запросу

Добавьте data-nl-thumbs контейнеру, чтобы включить ленту. Превью берётся из data-nl-thumb или вложенного изображения. Для видео без постера показывается номер.

АтрибутНазначение
data-nl-galleryИмя группы. Пустое значение открывает отдельный слайд.
data-nl-captionПодпись текущего слайда.
data-nl-altАльтернативный текст. По умолчанию берётся из вложенного img.
data-nl-labelДоступное имя галереи на открывающей ссылке.
data-nl-thumbURL миниатюры или постера видео.

Свайп работает через CSS Scroll Snap. Клавиатурные стрелки перелистывают вне полей ввода и плееров. Загружается только активное медиа, масштабирование остаётся штатной возможностью браузера. Открыть отдельный пример ↗

05 / Примеры

Видео в той же галерее

Файлы MP4 и WebM распознаются автоматически. Ссылки на YouTube, VK Видео, RUTUBE, Vimeo и Kinescope преобразуются во встроенный плеер. Внешние SDK не загружаются.

▷ВидеофайлНативный HTML-плеер↗▷YouTubeОтложенная загрузка iframe↗
HTML 
<a href="/demo.mp4" data-nl-gallery="media">Видео</a>
<a href="https://youtu.be/M7lc1UVf-VE"
   data-nl-gallery="media">YouTube</a>

<!-- Видео по ссылке без расширения -->
<a href="/stream?id=42" data-nl-type="video"
   data-nl-gallery="media">Видео с CDN</a>

Для точного URL из кода встраивания используйте data-nl-embed. Передавайте значение src официального iframe. Vimeo сохраняет ключ h, RUTUBE — p, VK — hash.

СервисПоддерживаемая ссылка
YouTubeyoutu.be/ID, watch, shorts, live и embed
VK Видеоvkvideo.ru/video-OWNER_ID, video_ext.php
RUTUBErutube.ru/video/ID, private и play/embed
Vimeovimeo.com/ID, player.vimeo.com/video/ID
Kinescopekinescope.io/ID, kinescope.io/embed/ID

При уходе со слайда плеер удаляется, воспроизведение прекращается. При возврате ролик начинается заново. Доступность встраивания зависит от настроек автора видео.

06 / Справочник

JavaScript API

Используйте отдельные ESM-импорты, когда хотите управлять открытием из своего приложения.

JavaScript 
import { open, close } from 'nano-lightbox/core';
import { openGallery } from 'nano-lightbox/gallery';

open(dialog, trigger);    // trigger — необязательный элемент возврата фокуса
close(dialog, 'done');    // 'done' попадёт в dialog.returnValue

const gallery = await openGallery(link);
gallery?.addEventListener('nl:change', event => {
  console.log(event.detail.index); // Индекс слайда с нуля
});
МетодПоведение
open(dialog, opener?)Открывает готовый dialog. Повторный вызов для открытого окна пропускается.
close(dialog, value?)Закрывает окно через нативный close(). Освобождает прокрутку после события close.
openGallery(link)Возвращает Promise с диалогом. Во время загрузки или показа другой галереи возвращает undefined.
resolveMedia(src, options?)Экспорт providers. Возвращает type и src. Опции — type, embed, base.
createThumbs(dialog, links, go)Экспорт thumbs. Добавляет ленту, возвращает функцию update(index).
07 / Справочник

Оформление в CSS

Базовые стили подключаются отдельно. Меняйте переменные для конкретного диалога или оформляйте обычный <dialog> самостоятельно.

CSS 
#contact {
  --nl-surface: #fff;
  --nl-color: #20242c;
  --nl-radius: 12px;
  --nl-padding: 32px;
  --nl-backdrop: rgb(15 23 42 / .5);
  --nl-duration: 180ms;
}

#menu { --nl-drawer-width: 24rem; }

data-nl-modal включает базовое оформление окна. Для панели используйте data-nl-drawer. Анимация строится на @starting-style, allow-discrete и overlay. При prefers-reduced-motion движение отключается.

08 / Справочник

Совместимость и размер

Основное требование — нативный HTMLDialogElement.showModal(). Целевые минимумы — Chrome 100, Firefox 100 и Safari / iOS 15.5. Автотесты выполняются в текущих Chromium, Firefox и WebKit. Старые версии и физические телефоны требуют отдельной проверки.

Прокрутка и overscroll-behavior

Модалки, меню и лента слайдов используют overscroll-behavior: contain, чтобы ограничить передачу прокрутки при достижении края. Внутри слайда ограничена только вертикальная ось, у миниатюр — горизонтальная. Значение contain допускает упругий отскок.

Это дополнительное улучшение. Поддержка значения contain начинается с Chrome 63, Firefox 59 и Safari / iOS 16. В Safari есть ограничения для контейнеров без прокручиваемого переполнения. В Safari 15.5 свойство игнорируется, а фон блокирует ядро через фиксацию body и восстановление позиции при закрытии. CSS внешней страницы не управляет прокруткой внутри стороннего iframe.

У closedby есть fallback

Поддержка проверяется отдельно через 'closedBy' in dialog. Если свойства нет, библиотека сама обрабатывает нажатие на фон и событие cancel. Перетаскивание из содержимого на фон не закрывает окно.

closedbyФонEscКнопка закрытия
any · по умолчаниюДаДаДа
closerequest—ДаДа
none——Да

Задавайте доступное имя через aria-labelledby или aria-label, начальный фокус через autofocus на внутреннем элементе. Фокус остаётся в модальном окне и возвращается к открывающему элементу. Где новые CSS-переходы недоступны, окно закрывается сразу.
